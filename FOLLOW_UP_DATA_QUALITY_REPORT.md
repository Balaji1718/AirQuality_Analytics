## 2. Root Cause Analysis

### Malformed Entry Source
The numeric country entries ("0", "1", "2") originated from the **aqi_coverage_map.json** file generated by `discover_aqi_coverage.js`. 

**Root Cause:**
The coverage map directly copied object keys from OpenAQ API responses without validation. Some responses contained numeric keys or partial/test data that should have been filtered.

**Example from coverage map (aqi_coverage_map.json):**
```json
{
  "supported_countries": {
    "0": { "regions": {}, "aqi_sources": ["waqi"], "total_locations": 0 },
    "1": { "regions": {}, "aqi_sources": ["waqi"], "total_locations": 0 },
    "2": { "regions": {}, "aqi_sources": ["waqi"], "total_locations": 0 },
    "Indonesia": { ... },
    ...
  }
}
```

### Why It Happened
1. `discover_aqi_coverage.js` did not validate country names before inserting into the coverage map
2. `hierarchical_schema_design.js` used minimal checks (`if (!countryName || countryName.match(/^\d+$/))`) that only skipped some numeric entries
3. Migration runner did not validate the coverage map before population

## 4. Validation & Sanitization Hardening

### 4.1 populateHierarchy() - Enhanced Validation

**File:** `server/hierarchical_schema_design.js`

**New Validation Functions:**
```javascript
function isValidCountryName(name) {
  if (!name) return false;
  const n = String(name).trim();
  if (n.length < 2 || n.length > 100) return false;
  // Must contain at least one letter to avoid numeric-only keys
  if (!/[A-Za-z]/.test(n)) return false;
  return true;
}

function sanitizeIso2(v) {
  if (!v) return null;
  const s = String(v).trim().toUpperCase();
  return /^[A-Z]{2,3}$/.test(s) ? s : null;
}

function validateCoverageMap(coverageData) {
  const supported = coverageData?.supported_countries || {};
  const invalid = [];
  for (const k of Object.keys(supported)) {
    if (!isValidCountryName(k)) invalid.push(k);
  }
  return invalid;
}
```

**Enhanced Population Logic:**
```javascript
// Skip numeric and non-string country names
const countryName = String(countryNameRaw || '').trim();
if (!isValidCountryName(countryName)) {
  console.warn('Skipping invalid country key:', countryNameRaw);
  continue;
}

// Sanitize iso2 to 2-3 letter uppercase
sanitizeIso2(countryData.iso2) || null

// Skip empty state/city names
const stateName = String(stateNameRaw || '').trim();
if (!stateName) continue;

if (!city || !city.name) continue;
```

### 4.2 Migration Runner - Pre-Flight Check

**File:** `server/apply_hierarchy_migration_and_populate.js`

**New Pre-Check:**
```javascript
const { validateCoverageMap } = require('./hierarchical_schema_design');

// Validate coverage map and remove invalid country keys before populating
const invalidKeys = validateCoverageMap(coverageData);
if (invalidKeys.length > 0) {
  console.warn('⚠️ Coverage map contains invalid country keys that will be skipped:', invalidKeys);
  for (const k of invalidKeys) {
    delete coverageData.supported_countries[k];
  }
}
```
